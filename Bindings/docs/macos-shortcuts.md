# macOS Default Keyboard Shortcuts Reference

Sources: [Apple Support](https://support.apple.com/en-us/102650), [machow2.com](https://machow2.com/keyboard-shortcuts-for-mac/), [computingforgeeks.com](https://computingforgeeks.com/must-know-macos-keyboard-shortcuts/)

## Modifier Key Symbols

| Symbol | Key |
|--------|-----|
| ⌘ | Command (Cmd) |
| ⌥ | Option (Alt) |
| ⌃ | Control (Ctrl) |
| ⇧ | Shift |
| Fn | Function / Globe |

---

## System & Navigation

| Shortcut | Action |
|----------|--------|
| ⌘ + Space | Spotlight Search |
| ⌃ + Space | Switch input source |
| ⌘ + Tab | Switch between open apps |
| ⌘ + ` (backtick) | Cycle windows of current app |
| ⌘ + ⌥ + Esc | Force Quit dialog |
| ⌃ + ⌘ + Q | Lock screen |
| ⌘ + ⌥ + D | Show/hide Dock |
| Fn + F11 | Show Desktop |
| ⌘ + , | Open app Preferences |

## Window Management

| Shortcut | Action |
|----------|--------|
| ⌘ + W | Close current window |
| ⌘ + Q | Quit current app |
| ⌘ + M | Minimize window to Dock |
| ⌘ + H | Hide current app |
| ⌘ + ⌥ + H | Hide all other apps |
| ⌃ + ⌘ + F | Toggle full screen |
| ⌃ + ↑ | Mission Control |
| ⌃ + ↓ | App Exposé (current app windows) |
| ⌃ + ←/→ | Switch Spaces (desktops) |

## Window Tiling (macOS 15+)

| Shortcut | Action |
|----------|--------|
| Fn + ⌃ + ← | Tile left half |
| Fn + ⌃ + → | Tile right half |
| Fn + ⌃ + ↑ | Tile top half |
| Fn + ⌃ + ↓ | Tile bottom half |
